# Drive Cool – site de l'auto-école

Site vitrine statique (HTML/CSS/JS, sans dépendance) : page d'accueil avec
« Qui sommes-nous », « Nos bureaux » (Andenne & Wanze), « Horaires » et « Nous contacter ».

Direction artistique reprise du logo : asphalte noir, marquage blanc pointillé,
vert `#74b525` et panneau losange de route prioritaire.

Pour le voir : ouvrir `index.html` dans un navigateur.
